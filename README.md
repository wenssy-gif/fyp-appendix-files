# Final-Year Project Appendix Files

This repository contains supporting materials for the final-year project:

**Data-Driven Web-Based Service Quality Analysis for Enhancing Customer Satisfaction in Malaysia E-Banking**

## Repository Contents

### Data

Contains the anonymised and processed datasets used in the analysis.

### SPSS

Contains exported SPSS results for:

- Reliability analysis
- Descriptive statistics
- Exploratory factor analysis
- Pearson correlation
- Multiple linear regression

Contains the SPSS syntax used to conduct the statistical analyses.


## Malaysia E-Banking Service Quality Dashboard

### [Open Interactive Dashboard](https://wenssy-gif.github.io/fyp-appendix-files/malaysia-ebanking-service-quality-analysis/dashboard/)
